# Research Talk Trainer v0.13.1 Mobile Secure

GitHub Pages deployment package.

## GitHub Pages
Publish this folder as a GitHub repository, then enable GitHub Pages from the main branch / root.

## Security
- No research materials are bundled.
- Users import their own material ZIP on the device.
- Imported materials and progress stay in browser storage.
- JSZip is bundled locally.
- CSP and ZIP/schema validation are enabled.

## Important
The GitHub Pages URL itself is public unless you use a separate access-control solution.
Do not add unpublished research material files to this repository.
